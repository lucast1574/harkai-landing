# Harkai: imágenes para revisión conjunta

Cuatro escenas conceptuales, generadas como una misma familia visual para la landing y futura reutilización en Android. No son capturas de la aplicación ni datos en tiempo real.

- barrio: contexto del barrio, plaza y vecinos. Sección de contexto local.
- reportes: observación de una rama caída. Sección de reportes.
- mascotas: encuentro con un perro del barrio. Sección de mascotas.
- ayuda: colaboración entre vecinos. Sección de comunidad.

Originales PNG: 1536 × 1024, sin texto incrustado. Versiones WebP optimizadas con los mismos nombres. Mantener etiquetas y textos como componentes nativos, fuera de la imagen. No usar como capturas reales del producto en las tiendas.

Revisión visual conjunta: harkai-imagenes-conjunto.jpg. Pendiente de aprobación del conjunto antes de publicación. Integración Android fuera del alcance de esta actualización de la landing.
